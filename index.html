Simulación de Enfriamiento de un Servidor

(Método de Euler Explícito)

1. Caso Aplicado: Enfriamiento de un Servidor

Un servidor en un centro de datos se sobrecalienta tras un pico de procesamiento. Al activar el sistema de refrigeración, la tasa de variación de la temperatura $T$ respecto al tiempo $t$ (en minutos) se modela mediante la Ley de Enfriamiento de Newton:

$$\frac{dT}{dt} = -k (T - T_{\text{amb}})$$
  • $T(t)$: Temperatura del servidor en el instante $t$ (°C).
  • $T_{\text{amb}}$: Temperatura ambiente del centro de datos (°C).
  • $k$: Constante de transferencia térmica ($1/\text{min}$).
  • Condición inicial: $T(0) = 80^\circ\text{C}$, $T_{\text{amb}} = 20^\circ\text{C}$, $k = 0.5\,\text{min}^{-1}$.

2. Método Numérico: Euler Explícito

Discretizando la derivada mediante diferencias finitas hacia adelante con paso $h$, obtenemos la ecuación de recurrencia para calcular el siguiente estado:

$$T_{n+1} = T_n + h \cdot \left[ -k (T_n - T_{\text{amb}}) \right]$$

Criterio de Estabilidad Numérica: Para este modelo, la condición de estabilidad exige que $|1 - hk| < 1$, lo que equivale a $0 < h < 4$ para $k = 0.5$.
